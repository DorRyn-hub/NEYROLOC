# NEYROLOC — бренд

## Цвета (градиент-ядро)
Фирменный градиент идёт по диагонали (сверху-слева → снизу-справа):

| Токен            | HEX       | Где снят из логотипа       |
|------------------|-----------|-----------------------------|
| `brand-purple`   | `#8C49FE` | верх знака / начало         |
| `brand-blue`     | `#3667FF` | стрелка / середина          |
| `brand-bright`   | `#1098FF` | яркий синий                 |
| `brand-cyan`     | `#46CDF9` | «loc» / низ, кончик         |

Основной градиент: `linear-gradient(135deg, #8C49FE 0%, #3667FF 50%, #1098FF 100%)`.
Тёмный фон продукта: `#0d111a` (окно), `#161F3A→#0A0E1A` (подложка иконок).

## Ассеты
- `neyroloc-mark.svg` — знак (нейросеть-пин + стрелка), прозрачный вектор. Источник иконок.
- `neyroloc-logo-reference.png` — исходный референс логотипа (растр с текстом).
- `icon-store-alt.png` — альтернативная иконка (градиентный фон + белый знак) для стора/лендинга.
- `rdev-lockup-muted.svg` — приглушённый RDEV-локап для «created by» на тёмном фоне.

Знак → иконки генерируются рендером SVG (см. историю). Обработка: тёмная подложка + градиентный знак (вариант **B**).

## Куда проставлен
- **iOS**: AppIcon (1024), `Mark.imageset` (экран настройки), кнопка-градиент, `Rdev.imageset` («created by»).
- **Веб-клиент** (`NEYROLOCK_5/resources/mobile.html`): знак в шапке и на экране сопряжения, favicon, кнопки-градиент, «created by RDEV».
- **PWA/иконки**: `resources/icon-180|192|512.png`, `favicon.png`, `mark.svg`, `rdev.svg` (отдаёт `core/remote_server.py`).
- **Android**: `packaging/android/res/mipmap-*/ic_launcher.png` (нужна пересборка APK через `build_apk.sh`, чтобы иконка попала в сборку; внутренний UI уже брендирован через mobile.html).
