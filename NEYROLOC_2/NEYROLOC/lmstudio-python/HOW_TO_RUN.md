# 🚀 Как запустить LM Studio CLI

## ✅ Исправлено!

Теперь программа правильно обрабатывает отсутствие LM Studio и показывает подробные инструкции.

---

## 📋 Пошаговая инструкция

### Шаг 1: Установите LM Studio

1. Откройте браузер и перейдите на https://lmstudio.ai
2. Скачайте версию для вашей ОС (macOS/Windows/Linux)
3. Установите приложение
4. Запустите LM Studio

### Шаг 2: Скачайте модель

1. В LM Studio нажмите на вкладку **"Search"** (🔍) в левой панели
2. Найдите модель. Рекомендуемые варианты:

   **Для начинающих (быстрые, легкие):**
   - `Llama-3.2-3B-Instruct` - отличная модель для общения
   - `Qwen2.5-3B-Instruct` - хорошая альтернатива

   **Для более мощных систем:**
   - `Llama-3.2-7B-Instruct` - более умная, требует больше памяти
   - `Qwen2.5-7B-Instruct` - поддерживает function calling

3. Нажмите кнопку **"Download"** рядом с выбранной моделью
4. Дождитесь завершения загрузки

### Шаг 3: Загрузите модель в память

**⚠️ ВАЖНО:** Скачать модель недостаточно - ее нужно загрузить!

1. После завершения загрузки, перейдите в **"My Models"** (📦)
2. Найдите скачанную модель в списке
3. Нажмите кнопку **"Load in LM Studio"** или **"Load Model"**
4. Дождитесь, пока модель загрузится в память
   - Вы увидите прогресс-бар
   - После загрузки модель будет готова к использованию

### Шаг 4: Проверьте, что сервер запущен

1. В LM Studio должен быть индикатор **"Server Running"** (зеленый)
2. Обычно сервер запускается автоматически при загрузке модели
3. Если сервер не запущен:
   - Перейдите во вкладку "Local Server"
   - Нажмите "Start Server"

### Шаг 5: Запустите CLI

```bash
python lmstudio_cli.py
```

Если все настроено правильно, вы увидите:

```

👤 Вы: _
```

## 🐛 Что делать, если не работает?

### Проверка 1: Тест подключения

```bash
python test_connection.py
```

Этот скрипт покажет детальную информацию о проблеме.

### Проблема: "LM Studio is not reachable"

**Решение:**
1. Убедитесь, что LM Studio **запущен**
2. Убедитесь, что модель **загружена** (не просто скачана!)
3. Проверьте, что сервер активен (зеленый индикатор в LM Studio)
4. Попробуйте перезапустить LM Studio

### Проблема: "No loaded models"

**Решение:**
1. Откройте LM Studio
2. Перейдите в "My Models"
3. Нажмите "Load Model" на нужной модели
4. Дождитесь полной загрузки

### Проблема: Модель слишком медленная

**Решение:**
1. Используйте модель меньшего размера (3B вместо 7B)
2. В настройках LM Studio включите GPU acceleration (если доступно)
3. Уменьшите context length в настройках

### Проблема: Ошибка при установке зависимостей

**Решение:**
```bash
# Обновите pip
pip install --upgrade pip

# Переустановите зависимости
pip install --force-reinstall lmstudio rich
```

## 💡 Полезные советы

### Рекомендуемые модели для начала

| Модель | Размер | Плюсы | Минусы |
|--------|--------|-------|--------|
| Llama 3.2 3B | ~2GB | Быстрая, хорошо общается | Менее умная |
| Qwen 2.5 3B | ~2GB | Быстрая, хороший русский | - |
| Llama 3.2 7B | ~4GB | Умнее, лучше reasoning | Медленнее |
| Qwen 2.5 7B | ~4GB | Очень умная, function calling | Требует больше памяти |

### Настройки для лучшей производительности

В LM Studio:
1. **GPU Layers**: Максимум (если есть GPU)
2. **Context Length**: 2048-4096 для начала
3. **Temperature**: 0.7-0.8 для баланса креативности
4. **Max Tokens**: 512-1024 для обычных ответов

### Команды CLI

После успешного запуска попробуйте:

```
/help      - Справка по командам
/models    - Список загруженных моделей
/switch    - Переключить модель
/save      - Сохранить диалог
/history   - Показать историю
/clear     - Очистить историю
/exit      - Выход
```
