🚀 БЫСТРЫЙ СТАРТ (2 МИНУТЫ):

1️⃣  Установите зависимости:

   pip install -r requirements_ai_cli.txt

   Для Mac M1/M2/M3:
   CMAKE_ARGS="-DLLAMA_METAL=on" pip install llama-cpp-python
   pip install rich huggingface-hub

2️⃣  Запустите новый AI CLI:

   python ai_cli.py

3️⃣  Выберите "6" (Скачать модель)

   → Выберите категорию: small
   → Выберите модель: 1 (Llama 3.2 3B)
   → Дождитесь скачивания (~2GB)
   → Готово! Модель автоматически загрузится!

📱 ДОСТУПНЫЕ CLI:

⭐ ai_cli.py (НОВЫЙ!)
   → Универсальный CLI со всеми функциями
   → Поддержка 5 backend'ов
   → Встроенное скачивание с HuggingFace
   → Команда: python ai_cli.py

   → Локальные GGUF модели

   → Для работы с LM Studio
   → Команда: python lmstudio_cli.py

🌐 universal_cli.py
   → Для Ollama, Groq, OpenAI
   → Команда: python universal_cli.py

🛠️ model_manager.py (НОВЫЙ!)
   → Standalone менеджер моделей
   → Команда: python model_manager.py

🎯 РЕКОМЕНДУЕМЫЕ МОДЕЛИ:

Для начинающих (2GB):
  ⭐ Llama 3.2 3B - отличное качество от Meta
  ⭐ Qwen 2.5 3B - очень умная модель

Для тестов (300-700MB):
  🐣 Qwen 2.5 0.5B - супер быстрая
  🐣 Llama 3.2 1B - хороший баланс

Для продвинутых (4-5GB):
  💪 Qwen 2.5 7B - мощная модель
  💪 Llama 3.1 8B - топовое качество

Все модели скачиваются одной командой!

❓ FAQ:

Q: Где хранятся модели?
A: ~/.lmstudio_models/

Q: Сколько места нужно?
A: От 300MB (tiny) до 5GB (7B модели)

Q: Нужен ли интернет?
A: Только для скачивания, потом работает offline

Q: Какую модель выбрать?
A: Начните с Llama 3.2 3B (2GB) - отличный баланс

Q: Работает на Mac M1/M2/M3?
A: Да! Используйте CMAKE_ARGS при установке
