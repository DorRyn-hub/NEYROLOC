## 1️⃣ lmstudio_cli.py - Для работы С LM Studio

### Файлы:
- `lmstudio_cli.py` (18KB) - основной CLI
- `my_examples/` - 7 обучающих примеров
- Полная документация (9 файлов)

### Запуск:
1. Установите LM Studio с https://lmstudio.ai
2. Загрузите модель (Load, не просто Download!)
3. `python lmstudio_cli.py`

### Документация:
- `START_HERE.txt` - Быстрая памятка
- `QUICKSTART.md` - Быстрый старт
- `HOW_TO_RUN.md` - Подробное руководство
- `CLI_README.md` - Полная документация

## 2️⃣ universal_cli.py - БЕЗ LM Studio ⭐

### Что это:
Универсальный CLI, работающий **БЕЗ LM Studio**!

### Поддерживаемые backend'ы:
- ✅ **Ollama** (локально, бесплатно)
- ✅ **Groq** (облако, бесплатно, быстро)
- ✅ **OpenAI** (облако, платно)
- ✅ Любой OpenAI-совместимый сервер

### Быстрый старт с Groq (БЕЗ установки):

```bash
# 1. Получите бесплатный ключ
# https://console.groq.com (регистрация 1 минута)

# 2. Запустите CLI
python universal_cli.py

# 3. Выберите "3" (Groq)
# 4. Введите API ключ

# ✅ Готово! Очень быстро!
```

### Запуск с Ollama (локально):

```bash
# 1. Установите Ollama
brew install ollama

# 2. Запустите сервер (в отдельном терминале)
ollama serve

# 3. Загрузите модель
ollama pull llama3.2:3b

# 4. Запустите CLI
python universal_cli.py

# 5. Выберите "1" (Ollama)
```

### Документация:
- `START_WITHOUT_LMSTUDIO.txt` - Быстрая памятка
- `SETUP_WITHOUT_LMSTUDIO.md` - Полное руководство
- `WITHOUT_LMSTUDIO.md` - Краткое описание
