⚡ САМЫЙ БЫСТРЫЙ СПОСОБ (GROQ - БЕЗ УСТАНОВКИ):

1. Зарегистрируйтесь на https://console.groq.com (бесплатно)
2. Создайте API ключ
3. Запустите:
   python universal_cli.py
4. Выберите "3" (Groq)
5. Введите ваш API ключ

✅ Готово за 2 минуты! Очень быстрые ответы!

🏠 ДЛЯ ЛОКАЛЬНОЙ РАБОТЫ (OLLAMA):

# Установка Ollama
brew install ollama

# Запуск сервера (в отдельном терминале)
ollama serve

# Загрузка модели
ollama pull llama3.2:3b

# Запуск CLI
python universal_cli.py
# Выберите "1" (Ollama)
