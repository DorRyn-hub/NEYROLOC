Скрипт автоматически:
  ✅ Проверит Python
  ✅ Установит все зависимости (rich, huggingface-hub, llama-cpp-python)
  ✅ Для M1/M2/M3 включит Metal (GPU ускорение)
  ✅ Запустит AI CLI

Больше ничего не нужно!

📋 ЧТО ДЕЛАТЬ ДАЛЬШЕ:

После запуска скрипта:

1. Выберите "6" (Скачать модель)
2. Выберите "small" (Маленькие модели)
3. Выберите "1" (Llama 3.2 3B - 2GB)
4. Дождитесь скачивания (~2GB)
5. Готово! Начинайте общаться!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
