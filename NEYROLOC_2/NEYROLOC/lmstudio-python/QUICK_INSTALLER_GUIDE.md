# ⚡ Быстрое руководство по установщикам NEYROLOCK

## 🚀 Создание установщика за 3 шага

### Шаг 1: Создайте иконки (один раз)

```bash
python3 create_icons.py
```

### Шаг 2: Соберите установщик

```bash
bash build_installer.sh
```

Скрипт автоматически определит вашу ОС и создаст соответствующий установщик.

### Шаг 3: Найдите готовый установщик

```bash
ls -la installers/output/
```

**Вот и всё!** 🎉

## 📦 Что будет создано

### Windows
- `NEYROLOCK-3.0.0-Windows-Setup.exe` (~180 MB)
  - Установка в один клик
  - Автоматическое создание ярлыков
  - Прогресс-бар установки

### macOS
- `NEYROLOCK.app` (~250 MB) - Приложение
- `NEYROLOCK-3.0.0-macOS.dmg` (~180 MB) - Установщик
  - Красивый DMG с drag & drop
  - Поддержка Apple Silicon и Intel
  - Прогресс-бар сборки

### Linux
- `neyrolock_3.0.0_amd64.deb` (~120 MB) - Debian/Ubuntu
- `neyrolock-3.0.0-1.x86_64.rpm` (~115 MB) - Fedora/RedHat
- `NEYROLOCK-3.0.0-Linux-Installer.sh` (~125 MB) - Универсальный
  - Прогресс-бар установки
  - Работает на любом Linux

## 🎯 Для конечных пользователей

### Windows

1. Скачайте `NEYROLOCK-3.0.0-Windows-Setup.exe`
2. Запустите установщик
3. Следуйте инструкциям (прогресс-бар покажет каждый шаг)
4. Готово! Программа в меню "Пуск"

### macOS

1. Скачайте `NEYROLOCK-3.0.0-macOS.dmg`
2. Откройте DMG
3. Перетащите NEYROLOCK в Applications
4. Готово! Программа в Launchpad

### Linux (Debian/Ubuntu)

```bash
sudo dpkg -i neyrolock_3.0.0_amd64.deb
neyrolock  # Запуск
```

### Linux (Fedora/RedHat)

```bash
sudo rpm -i neyrolock-3.0.0-1.x86_64.rpm
neyrolock  # Запуск
```

### Linux (Универсальный)

```bash
sudo bash NEYROLOCK-3.0.0-Linux-Installer.sh
```

Прогресс установки:
```
[1/4] Подготовка к установке...
[2/4] Распаковка файлов приложения...
[3/4] Создание системных ссылок...
[4/4] Регистрация в системе...
✓ Установка завершена успешно!
```

## 🎨 Изменение иконки

1. Замените файл:
   ```bash
   cp your-new-icon.icns NEYROLOCK.app/Contents/Resources/AppIcon.icns
   ```

2. Создайте иконки для всех платформ:
   ```bash
   python3 create_icons.py
   ```

3. Пересоберите установщик:
   ```bash
   bash build_installer.sh
   ```

## ❓ Проблемы?

**Не работает сборка?**
1. Проверьте, что Python 3.10+ установлен
2. Проверьте логи в терминале
3. Прочитайте `INSTALLER_GUIDE.md` для деталей

**Большой размер установщика?**
- Это нормально для standalone приложения
- PyInstaller упаковывает Python и все библиотеки

**Иконка не отображается?**
- Запустите `python3 create_icons.py`
- Проверьте, что файлы созданы в `assets/`
