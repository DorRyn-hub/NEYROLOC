# LM Studio CLI - Консольный интерфейс для LM Studio

Полнофункциональный консольный интерфейс для работы с локальными LLM моделями через LM Studio.

## ✨ Особенности

- 🎨 **Красивый цветной интерфейс** с использованием Rich
- 💬 **Потоковые ответы** в реальном времени (как ChatGPT)
- 📝 **История диалогов** с возможностью сохранения
- 🔄 **Переключение между моделями** на лету
- ⌨️ **Система команд** для управления
- 💾 **Автоматическое сохранение** истории команд
- 🛡️ **Обработка ошибок** и корректное завершение

## 📋 Требования

- Python 3.10 или выше
- LM Studio (запущенный с загруженной моделью)
- Установленные зависимости из `requirements_cli.txt`

## 🚀 Установка

### 1. Установите LM Studio

Скачайте и установите LM Studio:
- Официальный сайт: https://lmstudio.ai
- Запустите LM Studio
- Скачайте и загрузите модель (например, Llama, Mistral, Qwen)

### 2. Установите Python зависимости

```bash
# Перейдите в директорию проекта
cd lmstudio-python

# Установите зависимости
pip install -r requirements_cli.txt

# Или установите вручную
pip install lmstudio rich
```

### 3. Запустите CLI

```bash
python lmstudio_cli.py
```

## 📖 Использование

### Основные команды

После запуска программы вам доступны следующие команды:

| Команда | Описание |
|---------|----------|
| `/help` | Показать справку по всем командам |
| `/exit` или `/quit` | Выйти из программы |
| `/models` | Показать список загруженных моделей |
| `/switch` | Переключиться на другую модель |
| `/history` | Показать историю текущего диалога |
| `/save` | Сохранить историю в файл |
| `/clear` | Очистить историю диалога |
| `/reset` | Создать новый чат |

### Горячие клавиши

- `Ctrl+C` - Прервать генерацию ответа
- `Ctrl+D` - Выход из программы
- `↑/↓` - Навигация по истории введенных команд

## 🔧 Настройка

### Изменение системного промпта

Вы можете задать собственный системный промпт при создании нового чата:

```
👤 Вы: /reset Ты эксперт по Python программированию
✓ Создан новый чат
```

### Расположение истории

История диалогов сохраняется в:
- macOS/Linux: `~/.lmstudio_cli/history/`
- Windows: `C:\Users\<username>\.lmstudio_cli\history\`

## ❓ Решение проблем

### LM Studio не отвечает

1. Убедитесь, что LM Studio запущен
2. Проверьте, что модель загружена (не просто скачана)
3. Убедитесь, что сервер активен (обычно на порту 1234)
4. Проверьте логи LM Studio на наличие ошибок

### Нет цветного вывода

Убедитесь, что установлена библиотека `rich`:
```bash
pip install rich
```

### Ошибка импорта lmstudio

Установите библиотеку:
```bash
pip install lmstudio
```

### Модель отвечает медленно

- Используйте модели меньшего размера (3B-7B параметров)
- Убедитесь, что модель загружена на GPU (если доступно)
- Проверьте настройки LM Studio

## 🐛 Известные ограничения

1. **Function calling** поддерживается не всеми моделями
2. Некоторые модели могут требовать специфичного форматирования промптов
3. Производительность зависит от вашего оборудования

## 💡 Советы по использованию

1. **Выбор модели**: Для начала используйте модели 3B-7B параметров
2. **Системный промпт**: Четко описывайте роль ассистента для лучших результатов
3. **История**: Регулярно сохраняйте важные диалоги с помощью `/save`
4. **Переключение моделей**: Разные модели лучше справляются с разными задачами
