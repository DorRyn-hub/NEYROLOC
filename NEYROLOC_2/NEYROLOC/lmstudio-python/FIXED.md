### Когда запустите LM Studio:

1. Скачайте LM Studio с https://lmstudio.ai
2. Откройте приложение
3. Загрузите модель (рекомендуем Llama 3.2 3B или Qwen 2.5 7B)
4. Нажмите "Load Model" (не просто Download!)
5. Запустите CLI снова:
   ```bash
   python lmstudio_cli.py
   ```
