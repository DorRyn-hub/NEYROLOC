## 📦 Новые файлы

### 1. `model_manager.py` 🆕
**Менеджер для работы с моделями HuggingFace**

**Возможности:**
- ✅ Скачивание моделей с HuggingFace с прогресс-баром
- ✅ Рекомендуемые модели (от 300MB до 5GB)
- ✅ Поиск моделей по названию
- ✅ Просмотр скачанных моделей
- ✅ Управление локальной коллекцией
- ✅ Метаданные моделей (размер, путь, описание)

**Как использовать:**
```bash
# Standalone запуск
python model_manager.py

# Или импорт в другие скрипты
from model_manager import ModelManager

manager = ModelManager()
manager.download_recommended(category="small", index=0)
```

### 2. `ai_cli.py` ⭐
**Универсальный CLI с интеграцией HuggingFace**

**Возможности:**
- ✅ Поддержка 5 типов backend'ов (LM Studio, Ollama, Local GGUF, Groq, OpenAI)
- ✅ Скачивание моделей прямо из программы
- ✅ Переключение между backend'ами на лету
- ✅ Команда `/download` для скачивания моделей
- ✅ Команда `/switch` для смены backend

**Как использовать:**
```bash
python ai_cli.py
# Выберите backend или "6" для скачивания модели
```

### 3. Обновленный `local_model_cli.py` 🔄

**Новые команды:**
- `/download` - скачать модель с HuggingFace
- `/models` - показать скачанные модели
- `/search <запрос>` - найти модель на HuggingFace

**Как использовать:**
```bash
python local_model_cli.py

👤 Вы: /download
# Выберите из рекомендуемых или найдите свою модель

👤 Вы: /models
# Показывает все скачанные модели с возможностью загрузки

👤 Вы: /search llama
# Ищет модели Llama на HuggingFace
```

## 🔧 Технические детали

### Где хранятся модели?

По умолчанию: `~/.lmstudio_models/`

Структура:
```
~/.lmstudio_models/
├── unsloth_Llama-3.2-3B-Instruct-GGUF/
│   └── Llama-3.2-3B-Instruct-Q4_K_M.gguf
├── Qwen_Qwen2.5-3B-Instruct-GGUF/
│   └── qwen2.5-3b-instruct-q4_k_m.gguf
└── models_metadata.json  # Метаданные
```

### Как работает скачивание?

1. **Выбор модели** (рекомендуемая / поиск / ручной ввод)
2. **Скачивание** через `huggingface_hub` с прогресс-баром
3. **Сохранение метаданных** (путь, размер, описание)
4. **Возврат пути** к скачанной модели

### API менеджера моделей

```python
from model_manager import ModelManager

# Создание менеджера
manager = ModelManager()

# Показать рекомендуемые модели
manager.show_recommended_models()

# Скачать рекомендуемую модель
path = manager.download_recommended(category="small", index=0)

# Скачать свою модель
path = manager.download_model(
    repo_id="Qwen/Qwen2.5-3B-Instruct-GGUF",
    filename="qwen2.5-3b-instruct-q4_k_m.gguf"
)

# Интерактивное скачивание
path = manager.interactive_download()

# Показать скачанные
manager.show_downloaded_models()

# Список скачанных
models = manager.list_downloaded_models()

# Поиск на HuggingFace
manager.search_models("llama")
```

## ❓ FAQ по новым функциям

### Q: Сколько места нужно для моделей?

A: Зависит от выбора:
- Tiny модели: 300-700 MB
- Small модели: ~2 GB (рекомендуем начать с них)
- Medium модели: 4-5 GB
- Можно иметь несколько моделей для разных задач

### Q: Нужен ли интернет после скачивания?

A: Нет! После скачивания все работает полностью offline.

### Q: Можно ли удалить старые модели?

A: Да, просто удалите файлы из `~/.lmstudio_models/`

### Q: Как выбрать лучшую модель?

A: Начните с **Llama 3.2 3B** (2GB) - отличный баланс. Если медленно - попробуйте 1B или 0.5B. Если нужно лучше качество - 7B.

### Q: Работает ли на слабых компьютерах?

A: Да! Выбирайте tiny модели (0.5B-1B) с n_gpu_layers=0 (только CPU).
