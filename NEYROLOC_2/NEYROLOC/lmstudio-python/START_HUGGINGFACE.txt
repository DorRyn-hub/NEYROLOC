🚀 3 ШАГА ДО ЗАПУСКА:

1️⃣  УСТАНОВИТЕ ЗАВИСИМОСТИ

# Для Mac M1/M2/M3 (Apple Silicon)
CMAKE_ARGS="-DLLAMA_METAL=on" pip install llama-cpp-python rich

# Для Intel Mac
pip install llama-cpp-python rich

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2️⃣  СКАЧАЙТЕ МОДЕЛЬ

Откройте браузер:
→ https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF

1. Нажмите "Files and versions"
2. Найдите файл: qwen2.5-3b-instruct-q4_k_m.gguf
3. Нажмите на имя файла для скачивания
4. Дождитесь завершения (~2GB)

ДРУГИЕ ХОРОШИЕ МОДЕЛИ:
• Llama-3.2-3B-Instruct-GGUF (Meta)
• Mistral-7B-Instruct-GGUF (если есть 8GB+ RAM)

Ищите файлы с названием: *-Q4_K_M.gguf ⭐

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3️⃣  ЗАПУСТИТЕ CLI

python local_model_cli.py

→ Откроется Finder
→ Выберите скачанный файл .gguf
→ Нажмите Enter на все вопросы (используются умолчания)
→ Готово! Можно общаться!
