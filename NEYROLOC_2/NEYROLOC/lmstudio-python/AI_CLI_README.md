# 🤖 AI CLI v2.0 - Универсальный интерфейс для работы с AI

## 🌟 Что нового?

**AI CLI** - это улучшенная версия ваших CLI с интеграцией HuggingFace!

### ✨ Ключевые возможности:

1. **Скачивание моделей прямо из программы!** 🚀
   - Не нужно открывать браузер
   - Не нужно сворачивать программу
   - Выбор из рекомендуемых моделей
   - Поиск по HuggingFace

2. **Поддержка множества backend'ов:**
   - LM Studio (локально)
   - Ollama (локально)
   - Локальные GGUF модели (любые с HuggingFace)
   - Groq (облако, бесплатно, очень быстро)
   - OpenAI (облако, платно)

3. **Управление моделями:**
   - Просмотр скачанных моделей
   - Поиск моделей на HuggingFace
   - Удаление ненужных моделей

## 🚀 Быстрый старт

### 1️⃣ Установка зависимостей

```bash
pip install -r requirements_ai_cli.txt
```

Для Mac M1/M2/M3 (Apple Silicon):
```bash
CMAKE_ARGS="-DLLAMA_METAL=on" pip install llama-cpp-python
pip install rich huggingface-hub
```

### 2️⃣ Запуск

```bash
python ai_cli.py
```

### 3️⃣ Выбор backend

При первом запуске выберите backend:

```
╔═══════════════════════════════════════════════════════════╗
║                    🤖 AI CLI v2.0                         ║
║         Универсальный интерфейс для работы с AI           ║
╚═══════════════════════════════════════════════════════════╝

# Backend       Описание                         Требования
───────────────────────────────────────────────────────────────
1 LM Studio    Локальный, полнофункциональный   LM Studio + модель
2 Ollama       Локальный, простой               Ollama + модель
3 Local GGUF   Локальный, любые модели          Файл .gguf
4 Groq         Облако, бесплатно, быстро        API ключ (бесплатный)
5 OpenAI       Облако, платно, качественно      API ключ (платный)
6 Скачать      HuggingFace → GGUF               Интернет
```

## 📥 Скачивание моделей

### Способ 1: При запуске программы

1. Запустите `python ai_cli.py`
2. Выберите "6" (Скачать модель)
3. Выберите категорию (tiny/small/medium)
4. Выберите модель
5. Дождитесь скачивания
6. Модель автоматически загрузится

### Способ 2: Из программы (команда /download)

```
👤 Вы: /download
```

Программа покажет:
- Рекомендуемые модели (разных размеров)
- Возможность поиска по HuggingFace
- Возможность указать свою модель

### Способ 3: Standalone менеджер моделей

```bash
python model_manager.py
```

## 🔧 Модули проекта

### 1. `ai_cli.py` ⭐ НОВЫЙ
Универсальный CLI с поддержкой всех backend'ов и интеграцией HuggingFace.

**Возможности:**
- Выбор backend при запуске
- Скачивание моделей прямо из программы
- Переключение между backend'ами
- Единый интерфейс для всех типов моделей

### 2. `model_manager.py` 🆕 НОВЫЙ
Менеджер для скачивания и управления моделями с HuggingFace.

**Возможности:**
- Скачивание с прогресс-баром
- Рекомендуемые модели
- Поиск по HuggingFace
- Управление локальными моделями

### 3. `local_model_cli.py` 🔄 ОБНОВЛЕН
CLI для работы с локальными GGUF моделями.

**Новые команды:**
- `/download` - скачать модель
- `/models` - показать скачанные модели
- `/search` - найти модель на HuggingFace

### 4. `lmstudio_cli.py`
CLI для работы с LM Studio (без изменений).

### 5. `universal_cli.py`
CLI для работы с Ollama, Groq, OpenAI (без изменений).

## ❓ FAQ

### Q: Где хранятся скачанные модели?

A: В `~/.lmstudio_models/` (можно изменить в model_manager.py)

### Q: Сколько места занимают модели?

A:
- Tiny (0.5-1B): 300-700 MB
- Small (3B): ~2 GB
- Medium (7-8B): ~4-5 GB

### Q: Можно ли удалить ненужные модели?

A: Да, через `model_manager.py` или вручную из `~/.lmstudio_models/`

### Q: Нужен ли интернет для работы?

A: Только для скачивания моделей. После скачивания работает полностью offline.

### Q: Какую модель выбрать для начала?

A: **Llama 3.2 3B** - отличный баланс размера и качества.

### Q: Работает ли на Mac M1/M2/M3?

A: Да! Используйте CMAKE_ARGS при установке llama-cpp-python.

### Q: Можно ли использовать свои модели?

A: Да! Любые GGUF модели с HuggingFace или локальные файлы.

## 🐛 Troubleshooting

### Ошибка: "model_manager.py не найден"

```bash
# Убедитесь что model_manager.py в той же папке
ls model_manager.py

# Или установите зависимости
pip install huggingface-hub
```

### Ошибка: "llama-cpp-python not found"

```bash
# Для Mac M1/M2/M3
CMAKE_ARGS="-DLLAMA_METAL=on" pip install llama-cpp-python

# Для других систем
pip install llama-cpp-python
```

### Медленное скачивание

- Используйте VPN если HuggingFace заблокирован
- Проверьте скорость интернета
- Выберите модель меньшего размера (Q4 вместо Q8)

### Модель не помещается в памяти

- Выберите модель меньшего размера (3B вместо 7B)
- Используйте версию Q4 вместо Q8
- Уменьшите n_ctx (контекст)
- Поставьте n_gpu_layers=0 (только CPU)
