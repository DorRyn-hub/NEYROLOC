# NEYROLOCK - Быстрый старт для Windows 11

## 5 минут до первого запуска

### 1. Установите Python

```cmd
winget install Python.Python.3.12
```

Или скачайте с [python.org](https://python.org/downloads/) - **обязательно отметьте "Add Python to PATH"**

### 2. Запустите автоустановку

Дважды кликните на файл:
```
setup_and_run.bat
```

Скрипт:
- Проверит Python
- Установит все зависимости
- Запустит NEYROLOCK

### 3. Скачайте модель

В приложении:
1. Нажмите **"Скачать модель"** в боковой панели
2. Выберите категорию **"small"** (для начала)
3. Выберите **"Llama 3.2 3B"** (~2 GB)
4. Дождитесь скачивания

### 4. Начните диалог

- Введите сообщение в поле внизу
- Нажмите **Enter** или кнопку **"Отправить"**

## Горячие клавиши

| Действие | Windows |
|----------|---------|
| Сохранить | `Ctrl+S` |
| Очистить историю | `Ctrl+N` |
| Скачать модель | `Ctrl+D` |
| Загрузить модель | `Ctrl+L` |
| Выход | `Alt+F4` |

**Русская раскладка тоже работает:** `Ctrl+Ы` = `Ctrl+S`

## Альтернативные способы запуска

| Действие | Команда |
|----------|---------|
| Dashboard v3.0 | `run_neyrolock.bat` |
| GUI v2.0 + Telegram | `run_gui_v2.bat` |
| CLI интерфейс | `run_ai_cli.bat` |

## Проблемы?

### Python не найден
Переустановите с галочкой "Add Python to PATH"

### Медленная генерация
Используйте меньшую модель (3B вместо 7B) или установите GPU ускорение
