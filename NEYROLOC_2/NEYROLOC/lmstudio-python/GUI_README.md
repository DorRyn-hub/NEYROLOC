# 🖥️ AI GUI - Графический интерфейс с меню

## 🚀 Запуск

```bash
cd $HOME/PycharmProjects/NEYROLOCK/lmstudio-python
python3 ai_gui.py
```

или через скрипт:

```bash
./run_gui.sh
```

---

## 🎯 Что это?

**AI GUI** - это графический интерфейс с меню сверху окна для управления всеми функциями. Больше не нужно запоминать команды!

---

## 📋 Меню программы

### 📁 Файл
- 💾 **Сохранить диалог** (Cmd+S) - сохранить историю в JSON
- 📂 **Загрузить диалог** - загрузить сохраненный диалог
- 🗑️ **Очистить историю** - очистить текущий диалог
- ❌ **Выход** (Cmd+Q) - закрыть программу

### 🤖 Модели
- 📥 **Скачать модель с HuggingFace** - выбор и скачивание моделей
- 📂 **Загрузить локальную модель** - загрузить .gguf файл
- 📋 **Показать скачанные модели** - список и выбор моделей
- 🔍 **Найти модель на HuggingFace** - поиск моделей
- ℹ️ **Информация о текущей модели** - детали загруженной модели
- 🔄 **Выгрузить модель** - освободить память

### ⚙️ Backend
- 🖥️ **Local GGUF** - локальные модели (рекомендуется)
- 🏠 **LM Studio** - подключение к LM Studio
- 🦙 **Ollama** - подключение к Ollama
- ⚡ **Groq** - облачное API (бесплатно)
- 🌐 **OpenAI** - облачное API (платно)

### 🔧 Настройки
- 🎨 **Размер шрифта** - изменить размер текста
- 📝 **Системный промпт** - задать роль AI
- 🌡️ **Температура генерации** - креативность ответов

### ❓ Помощь
- 📖 **Быстрый старт** - инструкции для начала
- ⌨️ **Горячие клавиши** - список сочетаний
- ℹ️ **О программе** - информация о версии

## 💡 Быстрый старт

### 1. Запустите GUI

```bash
python3 ai_gui.py
```

### 2. Скачайте модель

1. Меню **'Модели'** → **'Скачать модель с HuggingFace'**
2. Выберите категорию: **small** (рекомендуется)
3. Выберите модель: **Llama 3.2 3B** (2GB)
4. Нажмите **'Скачать'**
5. Дождитесь скачивания
6. Подтвердите загрузку модели

### 3. Начните диалог

1. Напишите сообщение в поле внизу
2. Нажмите **Enter** или кнопку **'Отправить'**
3. Дождитесь ответа (отображается в реальном времени)

| **Cmd+Q** | Выход из программы |

## 🔧 Технические детали

### Требования

```bash
pip3 install rich huggingface-hub llama-cpp-python openai
```

Tkinter уже встроен в Python на Mac.

### Архитектура

- **Tkinter** - GUI фреймворк (встроен в Python)
- **Threading** - асинхронная генерация ответов
- **ScrolledText** - область чата с прокруткой
- **Menu** - система меню сверху

### Конфигурация

Файлы сохраняются в: `~/.ai_gui/`

## ❓ FAQ

### Q: Почему окно не открывается?

A: Убедитесь что все зависимости установлены:
```bash
pip3 install rich huggingface-hub
```

### Q: Как изменить размер окна?

A: Просто растяните окно мышью. Минимальный размер: 900x700.

### Q: Можно ли использовать без интернета?

A: Да! После скачивания модели все работает offline.

### Q: Где хранятся настройки?

A: В папке `~/.ai_gui/`

### Q: Как остановить генерацию?

A: Нажмите кнопку 'Стоп' справа от поля ввода.
