## 📋 Детальная инструкция

### 1. Выбор модели на HuggingFace

#### Что такое GGUF?
GGUF - это формат квантованных моделей для llama.cpp. Они:
- Занимают меньше места
- Работают быстрее
- Требуют меньше RAM

#### Что такое квантизация (Q2, Q4, Q8)?

| Квантизация | Размер | Качество | RAM | Рекомендация |
|-------------|--------|----------|-----|--------------|
| Q2_K | Маленький | Базовое | ~2GB | Для слабых ПК |
| Q4_K_M | Средний | Хорошее | ~3-4GB | ⭐ Оптимально |
| Q5_K_M | Больше | Очень хорошее | ~4-5GB | Если есть RAM |
| Q8_0 | Большой | Отличное | ~6-8GB | Максимум качества |

**Рекомендация:** Начните с **Q4_K_M** - лучший баланс!

### 2. Как скачать модель

**Пример: Qwen2.5-3B-Instruct**

1. Откройте: https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF

2. Нажмите "Files and versions"

3. Найдите файл: `qwen2.5-3b-instruct-q4_k_m.gguf`

4. Нажмите на имя файла → начнется скачивание

5. Дождитесь завершения (файл ~2GB)

### 3. Запуск CLI

```bash
cd $HOME/PycharmProjects/NEYROLOCK/lmstudio-python
python local_model_cli.py
```

**Что произойдет:**

1. Покажется баннер и инструкции
2. Откроется Finder
3. Выберите скачанный файл .gguf
4. Программа спросит настройки:

   - **GPU слои:** нажмите Enter (-1 = все на GPU)
5. Модель загрузится в память
6. Можно общаться!

## 💡 Настройки загрузки

### Размер контекста (n_ctx)

Сколько токенов модель может "помнить":

- `1024` - короткие диалоги, меньше RAM
- `2048` - оптимально ⭐
- `4096` - длинные диалоги, больше RAM
- `8192` - очень длинные, требует много RAM

### GPU слои (n_gpu_layers)

Сколько слоев модели загрузить на GPU (видеокарту):

- `0` - только CPU (медленно, но работает везде)
- `-1` - все на GPU ⭐ (быстро, для Mac M1/M2/M3)
- `20-40` - часть на GPU, часть на CPU (компромисс)

**Для Mac с M1/M2/M3:** Используйте `-1` (все на GPU через Metal)

## 🔧 Решение проблем

### Ошибка: "llama-cpp-python not found"

```bash
# Для Mac M1/M2/M3
CMAKE_ARGS="-DLLAMA_METAL=on" pip install llama-cpp-python

# Для других систем
pip install llama-cpp-python
```

### Ошибка: "Not enough memory"

**Решения:**
1. Выберите модель меньшего размера (3B вместо 7B)
2. Используйте Q4 вместо Q8
3. Уменьшите n_ctx (например, 1024)
4. Установите n_gpu_layers=0 (только CPU)

### Модель отвечает медленно

**Решения:**
1. Установите n_gpu_layers=-1 (все на GPU)
2. Выберите модель меньшего размера
3. Убедитесь, что используете GGUF формат

### Finder не открывается

Запустите Python с поддержкой GUI:
```bash
pythonw local_model_cli.py
```
