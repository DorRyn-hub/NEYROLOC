🖥️  ВЕРСИЯ 1: ГРАФИЧЕСКИЙ ИНТЕРФЕЙС (GUI) ⭐ РЕКОМЕНДУЕТСЯ

   Отдельное окно с меню сверху!

   Запуск:
   python3 ai_gui.py

   или:
   ./run_gui.sh

   Преимущества:
   ✅ Меню сверху (Файл, Модели, Backend, Настройки, Помощь)
   ✅ Визуальные диалоги
   ✅ Горячие клавиши (Cmd+S, Cmd+Q)
   ✅ Не нужно запоминать команды
   ✅ Кнопки управления
   ✅ Цветной чат

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💻 ВЕРСИЯ 2: КОМАНДНАЯ СТРОКА (CLI)

   Текстовый интерфейс в терминале

   Запуск:
   python3 ai_cli.py

   или:
   ./setup_and_run.sh

   Преимущества:
   ✅ Легче на ресурсы
   ✅ Работает через SSH
   ✅ Скриптуемый
   ✅ Быстрый запуск

   • Привыкли к терминалу? → python3 ai_cli.py

🎯 ЧТО ДЕЛАТЬ ПОСЛЕ ЗАПУСКА:

   1. Скачайте модель:
      GUI: Меню 'Модели' → 'Скачать модель с HuggingFace'
      CLI: Выберите "6" (Скачать модель)

   2. Выберите категорию 'small' и модель 'Llama 3.2 3B' (2GB)

   3. Дождитесь скачивания (~2GB)

   4. Начинайте общаться!
