## 🚀 Как использовать

### Для разработчика (вы):

```bash
# 1. Создайте иконки (один раз)
python3 create_icons.py

# 2. Соберите установщик
bash build_installer.sh

# 3. Найдите готовый установщик
ls -la installers/output/
```

### Для пользователей:

**Windows:**
```
1. Скачать NEYROLOCK-3.0.0-Windows-Setup.exe
2. Запустить установщик
3. Видеть прогресс установки:
   [1/5] Проверка зависимостей...
   [2/5] Очистка старых сборок...
   [3/5] Сборка приложения...
   [4/5] Проверка Inno Setup...
   [5/5] Создание установщика...
4. Готово!
```

**macOS:**
```
1. Открыть NEYROLOCK-3.0.0-macOS.dmg
2. Перетащить в Applications
3. Готово!
```

**Linux:**
```bash
sudo dpkg -i neyrolock_3.0.0_amd64.deb  # Ubuntu/Debian
# или
sudo rpm -i neyrolock-3.0.0-1.x86_64.rpm  # Fedora/RedHat
# или
sudo bash NEYROLOCK-3.0.0-Linux-Installer.sh  # Универсальный
```
