# 🎬 Превью CLI интерфейса

## Как будет выглядеть интерфейс при запуске

### 1. Запуск приложения

```bash
$ python lmstudio_cli.py
```

```
╔═══════════════════════════════════════════════════════════╗
║                  LM STUDIO CLI INTERFACE                  ║
║                   Powered by lmstudio-python              ║
╚═══════════════════════════════════════════════════════════╝

Введите /help для справки или начните диалог

✓ Подключено к модели: llama-3.2-3b-instruct
```

---

### 2. Простой диалог

```
👤 Вы: Привет! Как дела?

🤖 Ассистент: Здравствуйте! У меня всё хорошо, спасибо что спросили.
Я AI ассистент, созданный чтобы помогать вам с различными задачами.
Чем могу быть полезен сегодня?
```

---

### 3. Команда /help

```
👤 Вы: /help

╔═══════════════════════════════════════════════════════════╗
║                         Справка                           ║
╚═══════════════════════════════════════════════════════════╝

Доступные команды:

/help              - Показать эту справку
/exit или /quit    - Выйти из программы
/models            - Показать список загруженных моделей
/switch            - Переключить модель
/history           - Показать историю текущего диалога
/save              - Сохранить историю в файл
/clear             - Очистить историю диалога
/reset             - Создать новый чат (с опциональным системным промптом)

Горячие клавиши:

Ctrl+C             - Прервать генерацию
Ctrl+D             - Выход
↑/↓                - Навигация по истории команд
```

## 🎨 Цветовая схема

- **Синий** (`👤 Вы:`) - Ввод пользователя
- **Зеленый** (`🤖 Ассистент:`) - Ответы модели
- **Желтый** - Команды и предупреждения
- **Красный** - Ошибки
- **Голубой** - Информационные сообщения
- **Серый** - Второстепенная информация

---

## ✨ Особенности интерфейса

### 1. Потоковый вывод
Текст появляется постепенно, как в ChatGPT - символ за символом

### 2. Красивые таблицы
Списки моделей и другая информация отображается в виде таблиц

### 3. Панели с рамками
Важная информация и справка отображается в красивых рамках

### 4. Эмодзи
Используются для визуального разделения пользователя и ассистента

### 5. Прогресс-индикаторы
При подключении показывается анимированный индикатор загрузки
