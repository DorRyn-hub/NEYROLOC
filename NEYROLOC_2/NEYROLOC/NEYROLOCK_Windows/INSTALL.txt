====================================================
           NEYROLOCK - AI Chat Interface
====================================================

БЫСТРЫЙ СТАРТ
=============

Windows:
--------
1. Запустите build_windows.bat (двойной клик)
2. Дождитесь создания NEYROLOCK.exe
3. Запустите NEYROLOCK.exe

macOS/Linux:
------------
1. Откройте терминал в папке проекта
2. chmod +x build.sh && ./build.sh
3. ./NEYROLOCK


ТРЕБОВАНИЯ ДЛЯ РАБОТЫ
=====================

Выберите ОДИН из вариантов:

Вариант 1: LM Studio (рекомендуется)
------------------------------------
1. Скачайте LM Studio: https://lmstudio.ai
2. Установите и запустите
3. Скачайте модель (например, Llama 3.2 или Qwen 2.5)
4. Нажмите "Load" чтобы загрузить модель
5. Запустите NEYROLOCK и выберите "1. LM Studio"

Вариант 2: Ollama
-----------------
1. Скачайте Ollama: https://ollama.com
2. Установите
3. В терминале: ollama pull llama3.2
4. Запустите: ollama serve
5. Запустите NEYROLOCK и выберите "2. Ollama"

Вариант 3: Groq (облако, бесплатно)
-----------------------------------
1. Зарегистрируйтесь: https://console.groq.com
2. Создайте API ключ: https://console.groq.com/keys
3. Запустите NEYROLOCK и выберите "3. Groq"
4. Введите API ключ


КОМАНДЫ В ЧАТЕ
==============

/help     - Справка
/clear    - Очистить историю
/history  - Показать историю
/save     - Сохранить диалог
/switch   - Сменить провайдера
/exit     - Выход

Ctrl+C    - Прервать генерацию


РЕШЕНИЕ ПРОБЛЕМ
===============

"Python не найден":
  - Установите Python с https://python.org
  - При установке отметьте "Add Python to PATH"

"Не удаётся подключиться к LM Studio":
  - Убедитесь что LM Studio запущен
  - Модель должна быть загружена (нажмите Load)
  - Порт по умолчанию: 1234

"Ollama не отвечает":
  - Запустите: ollama serve
  - Убедитесь что модель скачана: ollama list

"Неверный API ключ Groq":
  - Проверьте ключ на https://console.groq.com/keys
  - Создайте новый ключ если нужно
